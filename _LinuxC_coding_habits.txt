-> DEALING WITH ERRORS (CODE INSERTED):
two general method: 
1. return wrong value 
2. set global errno

When calling a function , check the return value, if wrong, printf some warnings
void die(const char* message){
    if(errno){      // system error, use perror to print the msg
        perror(message);
    }
    else{
        printf("ERROR: %s\n", message);     // other errors, customed print warning
    }
    exit(1);
}
